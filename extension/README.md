# 本地 m3u8 下载器助手（Edge/Chrome 扩展）

自己写的替代品：**嗅探网页里的 m3u8 / 视频 / 音频，一键交给本地下载器**。

- 没有远程脚本、不注入网页、不读 cookie，代码全在这几个文件里，随时可审计
- 下载/解密/合并交给本地 Python（AES-128、f95、ffmpeg 都在那边）

## 安装（开发者模式加载）

1. 打开 Edge：地址栏输入 `edge://extensions/`
2. 打开左下角（或右上角）的「**开发人员模式**」
3. 点「**加载解压缩的扩展**」，选这个 `extension` 文件夹
4. 扩展出现在列表里就装好了（建议把「在工具栏中显示」打开）

## 启动本地接收服务

双击同目录的 `启动扩展后端.bat`，看到：

```
→ 本地接收服务已启动：http://127.0.0.1:18888/api/ping
```

窗口保持开着。关掉就等于停止接收任务（正在下任务的会中断，已下分片会保留）。

## 用

1. 打开要下载的页面，**播放一下视频**（扩展靠观察网络请求抓 m3u8，不播放可能没请求）
2. 扩展图标上出现数字 = 抓到 N 个媒体
3. 点图标：
   - 列表里选一条点「下载」，或点「全部交给下载器」
   - 也可以在页面上右键 →「把本页媒体全部交给本地下载器」
4. 状态栏会显示进度，完成后文件落在本地服务配置的保存目录

## 设置

扩展图标 → 「设置」：

| 项 | 说明 |
|---|---|
| 本地服务地址 | 默认 http://127.0.0.1:18888 |
| 保存目录 | 由本地服务保存；留空 = 用户「下载」文件夹 |
| 缓存目录 | 分片临时目录；留空 = 保存目录下的「视频名.parts」 |

## 安全边界

- 扩展只申请 `webRequest`（观察）、`tabs`、`storage`、`contextMenus`、`notifications`
- **不注入 content script**，**不读 cookie**，**没有远程代码**
- 本地服务只监听 `127.0.0.1`，只接受 `Origin: chrome-extension://…` 的请求，
  网页脚本即使扫到端口也塞不进任务（会返回 403）

## 文件

```
manifest.json    MV3 声明
background.js    观察媒体请求 + 发送任务
popup.html/js/css 弹窗列表与进度
options.html/js  设置
icons/           图标
```
